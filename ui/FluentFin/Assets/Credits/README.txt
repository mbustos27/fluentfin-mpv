  TMDB's "Alt short (blue)" logo, from https://www.themoviedb.org/about/logos-attribution (downloaded 2026-11-22; its
  SHA-256 matched the fingerprint in TMDB's asset file name). Shown in Settings > About beside the notice "Nixie uses TMDB
  and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.", under TMDB's API terms of use and its
  logo and attribution guidelines: its colours, aspect ratio and orientation as TMDB draws it, smaller than Nixie's own
  marks. The file's one CSS rule (.cls-1{fill:url(#linear-gradient)}) is written as the path's fill attribute instead,
  because Windows' SVG renderer doesn't read <style> blocks; the drawing is the same.
